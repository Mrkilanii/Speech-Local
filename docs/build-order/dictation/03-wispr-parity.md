# 4 — Wispr Flow parity, first pass

**Status:** Building now · **Size:** L · [Back](README.md)

## What it does

Stops pasting your old clipboard (restores it only once the paste was read), never types into a password prompt, resolves spoken corrections ("2, actually 3", "scratch that", comma-wrapped "like"), drops the full stop in chat apps, pads short dictations with silence and keeps recording 150 ms past release.

## What you see

Short messages come through; "at 2, actually 3" types "at 3"; your clipboard is never pasted instead of what you said; menu items Paste last transcript and Restore previous clipboard.

## How we know it works

docs/verification.md clipboard check: 100 dictations into Claude, ChatGPT, Arc, Chrome and Terminal with SENTINEL-42 on the clipboard, pasted 0 times. **Not yet run live.** 435 unit tests pass; the lazy clipboard served another process and logged its read at +369 ms.
