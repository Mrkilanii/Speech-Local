# Decisions

**Reads:** nothing. These are settled.
**Does:** records a choice, the alternative, and the evidence.
**Writes:** one file per decision, numbered in the order they were taken.
**Human checks:** that the evidence is a measurement, not an argument.

A decision earns a file when a future session would otherwise re-litigate it or
quietly break it. Each names what was rejected and why — a decision without a
rejected alternative is just a description.

Where the evidence is a number, it belongs here with the number. Where it lives
in code, link the file rather than copying it.
